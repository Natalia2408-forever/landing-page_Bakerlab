# 🍪 Bakerlab Landing Page

A responsive landing page for a creative bakery, built from a Figma design. This project focuses on precise grid alignment, consistent typography and fluid responsiveness across all devices.

## 🔗 Live Demo

https://natalia2408-forever.github.io/landing-page_Bakerlab/

## 🧩 Description

This is a landing page built as part of an educational project. It demonstrates the ability to turn a high-fidelity designer mockup into clean, semantic and maintainable code, with attention to code organization and responsiveness.

## 🛠 Technologies

- HTML5 – semantic and accessible markup structure.
- SCSS – modular styles organized using the BEM methodology.
- Parcel – bundler for the dev server and the production build.
- ESLint + Prettier – code quality checks and consistent formatting.

## 🎯 Key Features

- Design accuracy – built to match the Figma design: proportions, typography, colors and spacing.
- Fully responsive layout – separate layouts for mobile (320px), tablet (640px), desktop (1024px) and wide desktop (1280px+) using a mobile-first approach.
- Custom grid system – a reusable SCSS grid mixin: 2 columns on mobile, 8 columns on tablet and desktop, fixed-width columns on wide screens.
- CSS Grid & Flexbox – product cards, statistics and footer built for flexible content flow.
- Clean and semantic HTML – BEM naming, landmarks (header, main, footer, nav) and aria-label attributes for links and navigation.
- Mobile menu without JavaScript – opens and closes using the CSS :target selector, with a smooth slide-in transition.
- Smooth interactions – hover effects for links and cards, smooth scrolling to page sections.
- Component states – buttons and links have default, hover and focus states from the design.

## ▶️ How to run

1. Clone the repository: git clone https://github.com/Natalia2408-forever/landing-page_Bakerlab.git
2. Navigate into the project directory: cd landing-page_Bakerlab
3. Install the dependencies: npm install
4. Run the app: npm start
